The System

Royal Jarvis is a local-first AI operating system.

It runs on one laptop. No cloud required. No API bills. No data leaves the machine it's running on.

What it does

  • Multi-agent orchestration — Hundreds of agents with defined roles, running on a 10-state task lifecycle.
  • Persistent memory — A layered memory substrate that remembers across sessions, with causal, counterfactual, and reflection records.
  • Cognitive stack — A 9-stage thought engine, metacognition, a verifier, a world model, and an intent predictor.
  • Voice and vision — Wake-word voice control and head-independent gaze tracking through an ordinary webcam.
  • Cryptographic audit — Every decision the system makes is hash-chained and independently verifiable.
  • 24/7 autonomy — Scheduled tasks that run without human intervention.

Under the hood

  • Python · Node · React · TypeScript
  • Ollama for local LLM inference
  • SQLite for structured memory
  • MediaPipe for vision
  • AES-256-GCM for secrets

What this isn't

Not a chatbot. Not a SaaS wrapper. Not an API client.

It's the infrastructure layer underneath all of those.
